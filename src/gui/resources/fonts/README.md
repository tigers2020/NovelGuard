# UI fonts

Place **Pretendard** files here for bundled typography (see [DESIGN.md](../../../../DESIGN.md)):

- `PretendardVariable.ttf` (preferred), or
- `Pretendard-Regular.otf`

Download from the official Pretendard release and include the license (OFL) in this folder.

If no file is present, the app falls back to **Noto Sans KR** and **Segoe UI**.
