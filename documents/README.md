# documents/ (historical)

This directory holds **legacy** research, plans, and session notes. It is **not** the place for new Superpowers workflow docs.

## New work

| Artifact | Location |
|----------|----------|
| Design specs | [`docs/superpowers/specs/`](../docs/superpowers/specs/) |
| Implementation plans | [`docs/superpowers/plans/`](../docs/superpowers/plans/) |
| Workflow index | [`docs/superpowers/README.md`](../docs/superpowers/README.md) |

## What stays here

- [`CURSOR_MEMO.md`](CURSOR_MEMO.md) — recurring agent mistakes and lessons
- Dated research/plan files (e.g. `2026-04-13_repo_cleanup_*`) — read-only history
- [`PLAN_TEMPLATE.md`](PLAN_TEMPLATE.md) — reference structure; copy into `docs/superpowers/plans/` for new plans
